# 밸런스 측정 round9 요약 (2026-10-19)

원본 로그: `round9_promote1.txt` (BalanceProbe.Report) · `round9_promote1.csv` (층별 Rows).
측정 상태 = 그 훈장의 '끝' 상태 (이전 트리 전부 + 지금 트리 전부 + 조각 합 = 다음 훈장 조건), 총공격·필살기 씀.

## 1. 측정 방식에서 알게 된 것

- **PromoteMode 2 (5초마다 일괄 승급)는 쓰면 안 됨**: 일괄 승급이 번식용 6마리만 남겨서 쥐가 6~15마리에 머묾 → 전투력이 크게 낮게 나옴 (1훈장 트리 전부로도 2층 실패). **PromoteMode 1 (인구가 꽉 찼을 때만 한 묶음)** 이 실제 플레이에 가까움.
- **9훈장 공용 스킬 '자동 승급'(Promote_Auto)도 같은 문제**: 켜져 있으면 쥐가 9마리 근처 → 9훈장 전투력이 8훈장보다 낮아짐. 측정 때는 `RatManager.AutoPromoteOn = false` 로 끔(측정 뒤 원래대로 켜 둠). **실제 플레이에서도 자동 승급이 오히려 약해지게 만드는 설계 문제 → 사용자에게 보고 필요** (남길 마릿수를 늘리거나, 꽉 찼을 때만 자동 승급 등).
- 유니티 창이 뒤에 있으면 측정이 거의 멈춤 (에디터 스로틀). 앞에 있으면 실시간의 10~15배.
- 시간 모델 `시간 = 목표 초 × h(r)`, r = 전투력/적정, h(r) = 0.5/r^2.5 + 0.5/r^1.5 (r<1), 1/r (r≥1) 은 1훈장 6층 예측 150초 vs 실측 153초로 대체로 맞음. 다만 지형 랜덤이라 편차 큼 (r 0.66 에 117초 같은 경우도 있음).
