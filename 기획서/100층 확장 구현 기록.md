## 사용자 결정 (2026-10-19)

- 16~30층 = **고양이 연구소로 교체** (기획안대로). 25층 해피 고양이 · 30층 팝 고양이. 예전 25 마녀 · 30 우주 사령관은 보스 테이블에 `floor 0` 으로 남김 (안 나옴, 테스트 패널로만 부를 수 있음).
- **초월 승급은 하지 않음** (초월 등급 · 새 친구 55종 · 신화→초월 승급 · 초월 2마리 노드 제외). 그래서 훈장 해금 보상의 '새 친구'는 비어 있고, 도감 조건(Dex_Count)은 지금 87종 기준으로 낮춤.
- 91~100 구간 보스 = **94 · 97 · 100층** (그 구간만 5층 규칙 예외, 95층은 일반 층).
- 보스마다 **새 밈 기술** (쿨타임 스킬 + 발악 1 · 2). 테이블만으로 고칠 수 있게 범용 패턴으로 만듦 (아래).
- 훈장·스킬 효과는 임의로 넓게 배분 · 밸런스는 임의 (측정 전).
- 그림은 전부 Codex CLI 시트 (한 장에 최대한 많이 → 자르기).

## 층 · 경제 (`Tools/gen_stage_table.py`)

- `FLOORS = 100`. 1~30층 값은 그대로. **31층부터 층마다 약 ×1.12** (유형별 `LATE_MUL` 허들 1.12 · 어려움 1.08 · 허들 1.14 · 어려움 1.08 · 허들 1.16, 5층 합 ≈ 1.12^5). 적정 찍찍 · 물건 체력 · 치즈 · 연구자료 모두 같은 비율.
- 보스 층 = `BOSS_FLOORS` (5~90 5층마다 + 94 · 97 · 100). 코드도 보스 테이블 floor 로 판단 (`StageManager.IsBossFloor` · `RunPage` · `Heist` → `GameDatabase.BossOf`).
- 건너뛰기 상한 `skip_cap`: 30층까지 기획서(최대 15), 31층~ 최고 클리어 층의 80% (5층 단위, 최대 80). 실제 시작 층 = min(1 + 스테이지 스킵 노드 합, 이 값). 9~16훈장 트리 스킵 노드 합으로 11훈장 ≈ 40 · 13훈장 ≈ 60 · 15훈장 ≈ 80 층.
- 마지막 층 `StageManager.lastFloor = 100` (씬 값도 100으로 바꿔야 함). 100층 클리어 → maxFloor 101 (훈장 조건 Boss_Clear 용).

## 밈 기술 = 범용 패턴 (`Hazards/Boss.Meme.cs`)

Atk_Type 시트에 새 칸 `pattern · sprite · size · color · popup · p1 · p2`. **pattern 이 있으면 코드 수정 없이 테이블 값만으로 동작**, 어느 칸(일반·두 번째·스킬·발악)에 넣어도 됨. 기존 29종(pattern 빈칸)은 예전 코드 그대로.
그림 `sprite` = `Assets/Art/Rats/BossMeme/<이름>.png` (Boss 인스펙터 `memeSprites`, 메뉴 Fill Meme Sprites). `@grill` 처럼 `@` 로 시작하면 보스 인스펙터의 기존 그림 (`@grill @gas @ice @coffin @maxwell @shark @money @banana @butter @flask @hairball @fireball`).

| 패턴 | 하는 일 (radius · stun · count · windup · dur 는 Atk_Type 기본 칸) | p1 · p2 |
|---|---|---|
| Drop | 쥐 무리 count 곳 경고 원 → 그림이 하늘에서 떨어짐 (dur 동안 차례로) | p1 착지 뒤: 0 사라짐 · 1~4 춤 · 5 p2초 머묾 · 6 쥐에게 걸어가 펑 |

## 공용 스킬 9~16훈장 (`Tools/gen_skill_tree.py`)

- 8훈장 트리 틀을 그대로 쓰고 값을 키움 (공격력 + = 25 × 1.6^(훈장-8) …) + 칸마다 효과를 훈장별로 돌려 씀 (`ROT` 표: 치명·다중 공격·보스·탄생·쌍둥이·황금 물건·가구·콤보·묘기·쥐덫·필살기·총공격·고양이·운석·전기 이빨·연쇄 폭발 …).
