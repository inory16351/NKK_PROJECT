# 스테이지 구간별 오브젝트 기획안 (16~100층)

★ = 밈 오브젝트, 괄호 안은 밈 원본

---

## 16~30 고양이 연구소

> **컨셉**: 고양이 관련 물건, 고양이 보스들 등장, 20층 보스 제로 유지

**일반**: 실뭉치 / 츄르 상자 / 스크래처 / ★오이 (오이에 놀라는 고양이) / 깃털 낚싯대 / 발자국 찍힌 비커 / ★화면에 "ffffffffff"가 끝없이 찍힌 노트북 (키보드 위를 걸어다니는 고양이) / ★딱 맞는 크기의 빈 박스 (If I fits, I sits) / ★가운데가 동그랗게 뚫린 식빵 한 장 (Cat Breading) / ★옆으로 넘어진 꽃병 (테이블에서 물건 떨어뜨리는 고양이)

**가구**: 대형 캣타워 / ★샐러드 접시가 놓인 흰 식탁 (고양이에게 소리치는 여자) / 펫 이동장 / 츄르 자판기 / ★봉고 드럼이 놓인 책상 (Bongo Cat)

**특수**: 황금 츄르 / ★고양이 귀가 달린 유리병에 가득 찬 황금 액체 (고양이는 액체다) / ★무지개 꼬리가 달린 황금 토스트 과자 (Nyan Cat)

**인간**: 털 범벅 집사 연구원 / 수의사 / 사료 배달원 / 큰 마스크를 쓴 알레르기 연구원

**보스**
- 20층 제로: 기존 디자인 유지
- 25층 ★해피 고양이 (Happy Cat): 혀를 내밀고 두 발로 뛰어오른 흰 고양이
- 30층 ★팝 고양이 (Pop Cat): 입을 동그랗게 벌린 고양이

---

## 31~45 지구과학 연구소

> **컨셉**: 자연사 박물관 + 연구소 컨셉(쥬라기 공원 시리즈 참고) / 화석이나 암모나이트 같은 화석 이미지의 오브젝트 등장 / 원시인 보스, 사육사 보스, 공룡탈 보스

**일반**: 암모나이트 / 삼엽충 화석 / 발자국 석고본 / ★원반 모양의 평평한 지구본 (Flat Earth) / 발굴용 곡괭이 / 호박 속 모기 / 공룡알 / ★픽셀 공룡이 뜬 모니터 (크롬 오프라인 공룡) / ★큼직한 공룡 모양 치킨너겟 (Dino Nuggets) / 공룡 머리 화석

**가구**: 티렉스 화석 전시대 / 유리 진열장 / 발굴 작업대 / 연구원 책상 / 매점 카운터

**특수**: 황금 공룡알 / 금괴가 갇힌 거대 호박 / 불타는 운석

**인간**: 고생물학자 / 조련사 / 견학 어린이 / ★검지를 까딱이며 고개 젓는 안경 쓴 프로그래머 (Ah ah ah, you didn't say the magic word)

**보스**
- 35층 원시인: 자기 횃불에 소스라치게 놀란 원시인
- 40층 ★랩터 사육사 (Clever girl): 수풀을 보며 감탄한 표정으로 엽총을 든 사육사
- 45층 ★공룡탈 알바 (공룡 풍선옷 춤 영상): 공기 주입식 티라노 옷을 입은 알바

---

## 46~60 연구소 확장 공사 현장

> **컨셉**: 공사장 관련 물건 / 공사장 인부들 등장 / 야가다 김씨, 노조 고양이, 함바집 아줌마

**일반**: ★"조아쓰"라고 적힌 안전모 (조아쓰) / 러버콘 / 시멘트 포대 / 찌그러진 노란 양은냄비 / 외발 수레 / 목장갑 / 철근 다발 / 믹스커피 상자 / ★"무재해 0일" 표지판 (Days since last accident: 0) / ★근육질 시바견과 축 처진 시바견이 그려진 안전 포스터 (Swole Doge vs Cheems)

**가구**: ★모서리에 불이 붙었는데 커피잔이 놓인 현장 사무 책상 (This is fine) / 비계 / 자재 팔레트 / 포크레인 / 식판이 산더미처럼 쌓인 함바집 수레

**특수**: 기공식 황금 삽 / 황금 쥐 장식 / 두툼한 노란 월급봉투

**인간**: ★애써 웃고 있는 백발 현장소장 (Hide the Pain Harold) / 신호수 / ★믹스커피 봉지로 커피를 젓는 인부 (믹스커피 봉지 젓기) / 철근 작업자

**보스**
- 50층 야가다 김씨: 굴착기 버킷에 올라탄 인부
- 55층 노조 고양이: 파업 조끼를 입고 드러누운 고양이
- 60층 ★함바집 아줌마 (살인의 추억 "밥은 먹고 다니냐?"): 고봉밥 쟁반을 든 아줌마, 대사는 "밥은 먹고 다니냐?"

## 61~75 수중 연구소

> **컨셉**: 해양 연구소 + 수산시장 컨셉 / 해산물, 산호 오브젝트 / 인어 고양이, 잠수복, 상어인데 등지느러미가 고양이

**일반**: 산호 조각 / 불가사리 / 소라 / 문어 항아리 / 광어 스티로폼 박스 / 빨간 고무대야 / ★"싯가" 가격판 (수산시장 싯가) / ★나무 판에 붙어 입을 벌린 물고기 장식 (Big Mouth Billy Bass) / ★집게를 번쩍 치켜들고 춤추는 꽃게 (Crab Rave) / ★축 늘어진 분홍 물고기 표본병 (블롭피시)

**가구**: 대형 수조 / 수산시장 좌판 / 표본 보관장 / 수산물 냉동고 / 산호 배양 탱크

**특수**: 진주가 보이는 거대 조개 / 경매 1호 황금 참치 / 등껍질에 보석이 박힌 다이아몬드 킹크랩

**인간**: 해양학자 / 다이버 / ★두 손가락을 펼쳐 수신호를 하는 생선 경매사 (묻고 더블로 가) / ★팔꿈치를 꺾어 소금을 뿌리는 선글라스 횟집 사장 (Salt Bae)

**보스**
- 65층 인어 고양이: 고양이 상반신과 물고기 꼬리
- 70층 잠수복 고양이: 투구 유리창 너머로 고양이 얼굴이 보이는 구식 잠수복
- 75층 상어 고양이: 상어 몸에 등지느러미가 고양이 귀 모양

---

## 76~90 2차대전 박물관

> **컨셉**: 2차대전 전쟁박물관 컨셉 / 탱크, 비행기, 무기 오브젝트 / 히틀러 고양이, 병사, 등에 탱크 포탑이 묶여 있는 고양이

**일반**: 철모 / 탄약 상자 / 무전기 / 전투식량 / 모형 전투기 / ★새빨간 드럼통 (빨간 드럼통은 터진다) / ★X가 적힌 커다란 키캡 (Press X to Doubt) / ★팔 걷어붙이고 이두박근을 보이는 쥐 선전 포스터 (We Can Do It) / ★군복 차림의 쥐가 정면을 손가락으로 가리키는 모집 포스터 (I Want You) / ★손바닥 자국 얼굴이 그려진 배구공에 철모를 씌운 것 (캐스트 어웨이 윌슨)

**가구**: 탄약 창고 / 작전 지도 테이블 / 야전 취사대 / 군용 지프 / 기념품 가판대

**특수**: 황금 훈장 / 낙하산 달린 보급 상자 / ★순금 프라이팬 (배그 프라이팬)

**인간**: 노병 해설사 / 군복 재연 배우 / 견학 학생 / 통신병

**보스**
- 80층 포탑 고양이: 등에 탱크 포탑이 묶여 있고, 포탑이 엉뚱한 방향을 향함
- 85층 ★라이언(사자) 이병 고양이 (라이언 일병 구하기): 사자 같은 모습의 이등병 고양이
- 90층 ★총통 고양이 (키틀러 + 몰락 벙커 장면): 콧수염 무늬 고양이가 안경을 벗고 연필을 쥔 분노 포즈

---

## 91~100 우주 연구소

> **컨셉**: NASA 컨셉 / 연료통, 비행기와 우주선 모형, 천체 모형 오브젝트 등장 / 우주복 보스, 우주 사령관 고양이

**일반**: 연료통 / 로켓 모형 / 행성 모형 / 동결건조 우주식량 / ★은박지로 접은 고깔모자 (Tinfoil Hat) / 망원경 / 위성 안테나 / 우주 헬멧 / ★"휴스턴" 직통 빨간 전화기 (Houston, we have a problem) / ★녹색 그래프가 가파르게 치솟는 관제 모니터 (Doge to the moon)

**가구**: 관제 콘솔 / 발사대 / 무중력 훈련 캡슐 / 천체투영기 / ★책 몇 권이 삐죽 튀어나온 책장 (인터스텔라 책장)

**특수**: 케이스에 든 빛나는 월석 / 황금 레코드 / ★테두리가 은은하게 빛나는 검은 직사각형 비석 (2001 스페이스 오디세이 모노리스)

**인간**: 관제사 / ★동료 등 뒤에서 바나나를 겨눈 우주비행사 (Always Has Been) / ★스튜디오 조명을 세팅하는 우주비행사 (달 착륙 조작설) / 커피 쏟는 관제소장

**보스**
- 94층 ★빨간 우주복 (어몽어스): 환풍구 뚜껑 위에 선 빨간 우주복
- 97층 ★레이저 눈 고양이 (레이저 눈 우주 고양이): 은하 배경을 두르고 눈에서 레이저가 나가는 고양이
- 100층 ★우주 사령관 고양이 (Grumpy Cat): 입꼬리가 축 처진 심술 얼굴의 사령관 고양이
